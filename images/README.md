# Логотип Own Keyboard Switch

- `Gemini_Generated_Image_hj42kdhj42kdhj42.jpg` — исходник, без изменений.
- `logo.png` — логотип в исходном разрешении с обрезанными полями и прозрачным
  внешним фоном. Белые буквы и разделители внутри сохранены.
- `logo-256.png` — квадратная версия с прозрачными отступами для значков окон.
- `logo-settings.png` — крупный логотип для левой панели настроек: 522×522,
  с белой обводкой контура. В интерфейсе уменьшен ещё на 5% относительно 165,3×165,3:
  размер 157,035×157,035 логические точки, непрозрачность 90,25%.
  Изображение подготовлено в тройном разрешении базового размера 174×174
  с обводкой 3 точки для экранов с высоким DPI.
- `okbswitch.ico` — значок EXE с размерами 16, 24, 32, 48, 64, 128 и 256 пикселей.

Контраст RGB увеличен на 5% относительно среднего серого:
`out = clamp((in - 0.5) * 1.05 + 0.5)`. Альфа-канал эта коррекция не затрагивает.
Контур выделяется по яркости в области логотипа, узкие белые разрывы замыкаются,
внутренние области заполняются. Край слегка сужен и сглажен для удаления белой
каймы JPEG. Геометрия обрезки рассчитана на исходник 2760×1504.

Повторная подготовка (Ubuntu/WSL, ImageMagick 7):

```bash
sudo apt install imagemagick
tools/prepare-logo.sh
```

Для локальной копии: `MAGICK=/path/to/magick tools/prepare-logo.sh`.
Обычная сборка Rust использует готовые PNG/ICO и не требует ImageMagick.
Изображения встраиваются в исполняемый файл; папка `images` при запуске не нужна.
Индикатор текущей раскладки в трее использует прежние буквы/флаги.
