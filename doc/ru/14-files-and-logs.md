# Файлы, папки и журналы

Точные пути на вашем компьютере показывает `okbswitch --paths`.

## Windows

Все рабочие файлы хранятся **внутри папки программы**:

| Что | Где |
|---|---|
| Программа (установка для всех) | `C:\Program Files\Okbswitch\okbswitch.exe` |
| Программа (установка для себя) | `%LOCALAPPDATA%\Programs\Okbswitch\okbswitch.exe` |
| Настройки, правила, исключения, записи автозамены | `data\config.toml` |
| История буфера обмена, если её сохранение включено | `data\clipboard-history.txt` |
| Блокировка единственного экземпляра | `data\okbswitch.lock` |
| Скачанные словари орфографии | `data\dictionaries\` |
| Журнал, файл на день, хранятся 7 последних | `Logs\okbswitch.<дата>.log` |
| Перенесённые файлы старых версий | `data\legacy-profile\` |

Автоматического перехода в `%APPDATA%` нет: если папка программы недоступна на
запись, программа сообщает об ошибке. Portable-версию держите в папке, куда
можно писать; установщик для всех пользователей сам выдаёт право записи в
`data` и `Logs`.

Для резервной копии настроек достаточно скопировать папку `data`.

## Linux

| Что | Установленный пакет | AppImage, `--portable` |
|---|---|---|
| Настройки | `~/.config/okbswitch/config.toml` | `data/config.toml` рядом с программой |
| Скачанные словари | `~/.config/okbswitch/dictionaries/` | `data/dictionaries/` |
| История буфера, если сохраняется | `~/.local/state/okbswitch/` | `data/` |
| Журналы | `~/.local/state/okbswitch/Logs/` | `Logs/` |
| Автозапуск | `~/.config/autostart/` | `~/.config/autostart/` |
| Правило udev | `/usr/lib/udev/rules.d/70-okbswitch.rules` | ставится помощником настройки |

## Файл настроек

`config.toml` — обычный текстовый файл TOML; окно настроек переписывает его при
**Применить**. Ручные правки вступают в силу после перезапуска программы. Если
в файле ошибка, программа не отказывается запускаться: синтаксическая ошибка
сбрасывает все настройки к значениям по умолчанию, неверное значение — только
свой параметр, испорченный элемент списка отбрасывается. Исходный файл при этом
сохраняется как `config.toml.invalid-<время>`, так что правки можно перенести
из него.

Настройки по умолчанию печатает `okbswitch --print-default-config`.

## Журнал

Журнал пишется, только если включено **Устранение проблем → Вести отладочный
журнал программы**, или на один запуск с параметром `--debug`. В нём нет
набранного текста и паролей — только служебные сведения, например:

```
word finished typed_in=Ru letters=4 stay_reason=None switch_reason=Some(ExtraRule) target=Some(En)
word converted from=ru to=en kind=Automatic
```

Этого достаточно, чтобы понять, почему слово было или не было исправлено, и
приложить журнал к сообщению об ошибке.
