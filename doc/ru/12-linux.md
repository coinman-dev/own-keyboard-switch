# Linux

Версия для Linux — предварительная. Она работает на x86_64 в таких сеансах:

| Сеанс | Как переключается раскладка | Что нужно |
|---|---|---|
| X11 (любой рабочий стол) | XKB | Ничего дополнительно |
| GNOME 45–50 на Wayland | Встроенное расширение GNOME Shell | Программа устанавливает его сама; после первой установки один раз выйдите из сеанса и войдите снова |
| KDE Plasma 6 на Wayland | Служба раскладок KDE и встроенный скрипт KWin | Программа устанавливает и загружает скрипт в текущем сеансе |

Другие композиторы Wayland (Sway, Hyprland и прочие) пока не поддерживаются.
Русская и английская раскладки должны быть добавлены в системных настройках
клавиатуры.

## Как это устроено

Программа читает клавиатуры через evdev и передаёт всё набранное дальше через
виртуальную клавиатуру uinput. Поэтому она работает во всех приложениях,
включая терминалы и окна Wayland. Как и у любого переключателя раскладки в
Wayland, доступ к клавиатурам по правилу udev позволяет программам вашего
пользователя читать нажатия клавиш. Сама Own Keyboard Switch всегда работает от
обычного пользователя; права администратора нужны только небольшому помощнику
настройки.

## Первый запуск

Окно **Настройка работы в Linux** показывает состояние по пунктам:
клавиатура, рабочий стол, раскладки, сеанс. Пока что-то не готово, программа не
перехватывает клавиши.

- **Настроить доступ к клавиатуре** — система запросит пароль администратора
  (pkexec) для помощника, который установит правило udev
  (`70-okbswitch.rules`) и загрузит модули `evdev` и `uinput`. Пакет `.deb`
  устанавливает правило сам, поэтому обычно этот шаг не нужен.
- **Настроить интеграцию рабочего стола** — установить для вашего пользователя
  расширение GNOME Shell или скрипт KWin. В GNOME после этого выйдите из сеанса,
  войдите снова и нажмите **Проверить снова**.
- **Начать работу** — когда всё готово.

Опция **Общие → Основные → Настраивать доступ к клавиатуре при запуске**
открывает это окно при каждом запуске, если доступа нет.

## Вкладка «Для Linux»

**Общие → Для Linux**:

- **Способ переключения** — «Автоматический выбор» использует XKB в X11 и
  интеграцию GNOME или KDE в Wayland. Можно выбрать явно «Система X11 (XKB)»,
  «Рабочий стол KDE» или «Расширение GNOME». Изменение применяется после
  проверки связи с рабочим столом; если выбранный способ недоступен, продолжают
  действовать прежние настройки.
- Отметка о том, установлено ли расширение GNOME программой.
- **Клавиатуры** — по одному пути устройства на строку, например
  `/dev/input/event3` или ссылка из `/dev/input/by-id`. Пустой список — все
  доступные клавиатуры. Применяется без перезапуска.

## Отличия от Windows

- Значок в трее: в KDE Plasma настройки открываются одним щелчком, в GNOME
  одиночный щелчок открывает меню.
- Нет опций «Запускать с правами Администратора» и «Исправлять раскладку при
  работе с меню».
- «Единая раскладка» не поддерживается в GNOME на Wayland.
- Программы-исключения в GNOME на Wayland работают только с расширением GNOME
  Shell.

## Команды

```sh
okbswitch --diagnose                   # сеанс, раскладки, доступ к устройствам
okbswitch --setup-linux-input          # повторить настройку доступа к клавиатуре
okbswitch --install-linux-integration  # повторить установку расширения GNOME / скрипта KWin
okbswitch --portable                   # хранить настройки рядом с программой
```

Полный список — в разделе [Командная строка](13-command-line.md).
