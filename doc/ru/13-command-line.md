# Командная строка

В Windows установленная программа называется `okbswitch.exe`, portable —
`okbswitch-portable.exe`; в Linux — `okbswitch` (или файл AppImage).

| Параметр | Что делает |
|---|---|
| `--settings` | Запустить и сразу открыть окно настроек |
| `-c`, `--config <файл>` | Использовать другой файл настроек. В Windows он должен лежать внутри папки программы |
| `-d`, `--debug` | Подробный журнал на этот запуск, с копией в терминал |
| `--no-tray` | Работать без значка в трее (остановка — Ctrl+C) |
| `--paths` | Показать, где лежат настройки, журнал и файл блокировки, и выйти |
| `--diagnose` | Проверить окружение: сеанс, раскладки, доступ к устройствам, автозапуск — и выйти |
| `--print-default-config` | Напечатать файл настроек по умолчанию и выйти |
| `--licenses` | Напечатать лицензию программы и уведомления о встроенных данных и выйти |
| `--version`, `--help` | Версия и справка |

Только Linux:

| Параметр | Что делает |
|---|---|
| `--portable` | Хранить настройки и журналы рядом с программой (в AppImage — всегда) |
| `--setup-linux-input` | Запросить права администратора и настроить доступ к клавиатурам |
| `--install-linux-integration` | Установить расширение GNOME Shell и скрипт KDE для текущего пользователя |

Запускается только один экземпляр программы на папку данных: повторный запуск
сообщает «okbswitch is already running» и завершается.

В Windows программа — оконное приложение: свой вывод (`--paths`, `--diagnose`)
она печатает в окно консоли, из которого её запустили. Запускайте такие команды
в открытом окне PowerShell или командной строки; при перенаправлении в файл
(`> out.txt`) вывод может туда не попасть.

```powershell
.\okbswitch-portable.exe --paths
.\okbswitch-portable.exe --diagnose
```
