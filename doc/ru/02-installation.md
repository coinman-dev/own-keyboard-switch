# Установка

Файлы выпуска лежат на странице
[Releases](https://github.com/coinman-dev/own-keyboard-switch/releases).

| Файл | Для чего |
|---|---|
| `okbswitch-portable.exe` | Windows без установки |
| `okbswitch-install.exe` | Установщик для Windows |
| `okbswitch_<версия>_amd64.deb` | Пакет для Ubuntu 24.04 и новее, Debian |
| `okbswitch-<версия>-x86_64.AppImage` | Linux без установки |

## Windows

### Portable

Положите `okbswitch-portable.exe` в папку, **куда можно писать** (например,
`D:\Tools\Okbswitch`), и запустите. Рядом появятся папка `data` с настройками и
папка `Logs` для журнала. В `C:\Program Files` portable-версию не кладите: там
у обычного пользователя нет права записи, и программа сообщит, что не может
сохранить настройки.

### Установщик

1. Запустите `okbswitch-install.exe` и выберите, для кого ставить:
   - **Только для меня** — в `%LOCALAPPDATA%\Programs\Okbswitch`, права
     администратора не нужны;
   - **Для всех пользователей** — в `C:\Program Files\Okbswitch`, Windows
     запросит права администратора. Установщик разрешит запись только в папки
     `data` и `Logs`, сам `okbswitch.exe` остаётся защищённым.
2. На странице компонентов можно отметить **Ярлык на рабочем столе** и
   **Запускать при входе в систему**. Автозапуск потом меняется в настройках
   программы.
3. Если программа уже работает, установщик завершит её перед заменой файлов.

### Обновление

Запустите установщик новой версии поверх старой или замените
`okbswitch-portable.exe` новым файлом, предварительно выйдя из программы
(меню трея → **Выйти**). Настройки сохраняются.

Настройки и история буфера из старых версий, которые хранили их в профиле
пользователя, при первом запуске переносятся в папку программы. Существующие
настройки не перезаписываются; старые журналы и конфликтующие файлы
откладываются в `data\legacy-profile`.

### Удаление

**Параметры Windows → Приложения → Own Keyboard Switch → Удалить.** Удаление
спросит, удалить ли также настройки, записи автозамены и историю буфера; если
собираетесь поставить программу снова, ответьте «Нет». Тихое удаление
(`uninstall.exe /S`) данные сохраняет. Portable-версию достаточно закрыть и
удалить вместе с папкой.

## Linux

Сначала добавьте русскую и английскую раскладки в системных настройках
клавиатуры.

### Пакет .deb

```sh
sudo apt install ./okbswitch_0.5.0-beta_amd64.deb
```

Пакет добавляет программу в меню приложений и устанавливает правило udev,
которое даёт пользователю активного локального сеанса доступ к клавиатурам и
`/dev/uinput`. Группа `input` и права root программе не нужны.

### AppImage

```sh
chmod +x okbswitch-0.5.0-beta-x86_64.AppImage
./okbswitch-0.5.0-beta-x86_64.AppImage
```

AppImage хранит настройки и журналы рядом с собой, как portable-версия для
Windows.

### Первый запуск в Linux

Окно **Настройка работы в Linux** проверяет доступ к клавиатуре, связь с
рабочим столом и раскладки и предлагает недостающие шаги: **Настроить доступ к
клавиатуре** (системный запрос пароля для помощника настройки) и **Настроить
интеграцию рабочего стола** (расширение GNOME Shell или скрипт KWin). Пока
настройка не завершена, клавиши не перехватываются. Подробнее — в разделе
[Linux](12-linux.md).

### Обновление и удаление

Новый пакет ставится той же командой `sudo apt install ./…deb`. Удаление —
`sudo apt remove okbswitch`; настройки в `~/.config/okbswitch/` остаются.
AppImage удаляется вместе с его папкой.
