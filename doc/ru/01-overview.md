# Что такое Own Keyboard Switch

Own Keyboard Switch (okbswitch) исправляет слова, набранные не в той раскладке:
`ghbdtn` → «привет», «руддщ» → `hello`. Вы печатаете как обычно; когда слово
закончено пробелом, Enter или знаком препинания, программа решает, на каком
языке оно написано, и при необходимости стирает его, переключает раскладку и
набирает слово заново. Работает в фоне, значок — в области уведомлений.

## Что программа умеет

- **Автопереключение RU/EN.** Решение принимается по встроенным словарям,
  частотам слов, статистике сочетаний букв и дополнительным правилам. Знает
  названия программ, команды Windows и Linux и слова языков программирования.
- **Break** отменяет последнее исправление или, наоборот, переводит слово,
  которое программа не тронула. Если отменять одно слово несколько раз подряд,
  программа предложит правило для него.
- **Пароли.** Пароль, набранный в русской раскладке, перепечатывается
  по-английски; в поле пароля английская раскладка включается с первого
  символа.
- **Регистр.** Исправляет «ПРивет» и текст, набранный со случайно включённым
  Caps Lock.
- **Работа с текстом:** смена раскладки, регистра и транслитерация выделенного
  текста и буфера обмена, вставка без форматирования, число прописью.
- **Автозамена:** сокращения разворачиваются в готовый текст, в том числе
  многострочный, с запоминаемым местом курсора.
- **Проверка орфографии** по команде или прямо при наборе.
- **История буфера обмена**, плавающий индикатор раскладки, флаги в трее,
  звуки, переключение раскладки одной клавишей, кнопки мыши с назначенными
  сочетаниями клавиш.

## Чего программа не делает

- **Не отправляет текст в сеть.** Словари и языковые модели встроены. Сеть
  нужна, чтобы скачать дополнительный словарь орфографии, когда вы сами
  нажмёте «Загрузить», и раз в неделю — чтобы спросить у GitHub список
  выпусков и узнать, нет ли новой версии. О вас ничего не передаётся; частоту
  проверки или её отключение выбирают в разделе «О программе». Рекламы нет.
- **Не пишет набранный текст в журнал.** В журнале есть только служебные
  сведения: сколько букв было в слове, какое принято решение, почему.
- **Работает только с парой «русский — английский».** Другие раскладки можно
  оставить в системе: по умолчанию ввод в них программа не трогает.
- Буферные операции работают с **обычным текстом**: картинки и форматирование
  не сохраняются.

## Главное на одной странице

| Нужно | Как |
|---|---|
| Открыть настройки | Двойной щелчок по значку в трее (в KDE Plasma — один щелчок) |
| Отменить исправление или перевести слово вручную | **Break** (Pause) сразу после слова |
| Перевести выделенный текст в другую раскладку | **Shift+Break** |
| Сменить регистр выделенного текста | **Alt+Break** |
| Транслитерировать выделенный текст | **Alt+Scroll Lock** |
| Вставить без форматирования | **Ctrl+Alt+V** |
| Временно выключить автопереключение | Меню трея → **Автопереключение** |
| Не переключать в определённой программе | [Программы-исключения](08-rules-and-exclusions.md#программы-исключения) |
| Слово переключается неправильно | Break, затем [правило](08-rules-and-exclusions.md#правила-переключения) |

## Системные требования

- Windows 10 или 11, x64.
- Linux x86_64: сеанс X11 с любым рабочим столом, GNOME 45–50 или KDE Plasma 6
  на Wayland. Подробности — в разделе [Linux](12-linux.md).
- В системе должны быть добавлены русская и английская раскладки.
