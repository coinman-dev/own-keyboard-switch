# Language data: sources and licenses

Own Keyboard Switch embeds language data derived from the sources below.
The data is generated by `tools/build-lang-data` from files downloaded by
`tools/fetch-lang-sources.sh`.

| Embedded file | Source | License |
|---|---|---|
| `ru_RU.aff`, `ru_RU.dic` | Russian Hunspell dictionary by Alexander I. Lebedev, from the LibreOffice dictionaries repository. Unmodified, compressed | BSD-style, reproduced below |
| `en_US.aff`, `en_US.dic` | English Hunspell dictionary from SCOWL by Kevin Atkinson, version 2020.12.07, from the LibreOffice dictionaries repository. Unmodified, compressed | SCOWL permissive license, see `data/hunspell/README_en_US.txt` |
| `ru.lm`, `en.lm` | Letter trigram statistics and word frequency ranks computed from the dictionaries above and from Tatoeba sentences | Tatoeba: CC-BY 2.0 FR, https://tatoeba.org |
| `eval-ru.tsv`, `eval-en.tsv` (tests only) | Word frequencies of held-out Tatoeba sentences | CC-BY 2.0 FR |
| `extra.rules.z` | Externally supplied layout rules, database 20170627 | Redistribution terms have not been established; not covered by the project's source-code license |
| `extra-short-en.txt` | Exact English targets derived from a user-supplied short-word evaluation list | Redistribution terms have not been established; not covered by the project's source-code license |

`tools/import-extra-rules.py` reproduces the rule artifact from the original data.
Source and artifact hashes are in `data/generated/extra.rules.json`. Only rule data
is embedded; executable code, DLLs and network components are not.

`tools/build-extra-short-rules.py --report <local-report.tsv>` regenerates the
additional short-word targets; `--check` verifies the existing artifact. The
source report's SHA-256 is recorded in its header. The original report is not
required to build or run the application. The optional contextual layer validates
Russian words and names at runtime; membership in the target list alone does not
request a conversion.
